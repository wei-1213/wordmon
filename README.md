# Wordmon｜魔法學院的單字精靈

用玩遊戲的方式學單字。扮演魔法學院的見習魔法師，答題賺經驗和金幣，培育六大元素的精靈。

**線上玩：** [https://你的帳號.github.io/wordmon/](https://wei-1213.github.io/wordmon/)

## 玩法

- 支援四種語言：韓文、越南文、日文、英文，每種 300 字。
- **單字試煉**：每次十題四選一，答對得 EXP、金幣和精靈能量。
- **精靈牧場**：用能量培育精靈，達到條件後進化。
- **元素圖鑑**：火、水、木、雷、冰、幻，每個元素兩隻，共 12 隻。其中六隻要用金幣購買。
- **更多**：精靈猜猜看（60 秒賺金幣）、錯題複習、成就、設定。

## 使用方式

不用安裝，打開網址就能玩，手機和電腦都可以。進度存在瀏覽器裡，換裝置或清除瀏覽器資料會從頭開始。

## 檔案

整個遊戲只有一個 `index.html`，沒有後端，也不用登入。

## 想自己改

用文字編輯器打開 `index.html`，檔案最上方的註解有說明如何新增單字和精靈。
